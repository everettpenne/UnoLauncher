# Uno Launcher 0.69.0-uno01

A smoother peek, one accent colour, and a cleaner wording of what Uno is for.

## What's new

- **Peek without the jitter.** The island used to re-compose on almost every touch while you pulled it down; now a pull only moves and draws it. No stretch or squash under the finger, no ring or bubbles hanging off a peek, no cut-off text while it opens, and the bottom of a part-open island fades instead of slicing a line of text.
- **One accent colour.** Switches, checkmarks, radios, sliders, buttons, chips, the chosen wallpaper and the News feed's chips and "new" count all use the same accent (the wallpaper's, or orange), instead of green beside orange beside teal.
- **No foldable references.** The docs and the welcome sheet describe a phone (and a "wide window"); the Home layout presets are "Single page" and "Wide".
- Everything from 0.68.0 (legible app names, double-tap to lock) and 0.67.0 (peek, hold open, recent notification, large navigation, smarter autocorrect) is unchanged.

## Notes: what this has and hasn't been tested on

Unit tests pass, and the island's instrumented tests (including new ones that sample the island's height frame by frame through a pull and count compositions) and the accessibility audit pass on an Android 16 emulator. **It has not been run on a real phone**; whether the pull now feels smooth is a thing only a finger can say, and the emulator cannot measure frame times. See `docs/device-checklist.md`.
