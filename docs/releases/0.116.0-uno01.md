# Uno Launcher 0.116.0-uno01

Dark icons that keep their colour.

## What's changed

- **Dark icons** (the Dark style, and Auto while dark): a white or black glyph takes the colour of its app's own icon background, on the near-black tile, so the launcher keeps its colour in dark mode.

## Install

Use **UnoLauncher-0.116.0-uno01-release.apk** from the release assets. Signed with the same key as 0.48.1 to 0.115.0-uno01, so it installs directly over them. Updating can switch off Notification access for Uno; turn it on again if the island loses track titles and artwork (Settings › Apps › Special app access › Notification access on GrapheneOS).
