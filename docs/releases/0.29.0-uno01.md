# Uno Launcher 0.29.0-uno01

Smaller large folders, and three new things for the island.

## What's new

- **Large folders in 2 × 1 and 1 × 2.** Pick "Large folder, wide" or "Large folder, tall" from the widget picker, or resize any large folder down (never to 1 × 1). Thin folders show compact icons.
- **Audio alerts.** The island shows the name of Bluetooth audio, a headset or headphones when they connect or disconnect. No permission needed, and there is a switch.
- **Screen recording mark.** A red dot on the island while your screen is being recorded (Android 15 and later). It uses Android's normal DETECT_SCREEN_RECORDING permission, granted at install, and learns only that recording is happening.
- **Time to full.** Open the island while charging and it says how long until the battery is full.

## Download and install

Use **UnoLauncher-0.29.0-uno01-release.apk** from the release assets. Signed with the same key as previous Uno releases, so it installs directly over 0.28.0. It still cannot install over a jakesgoodapps Duo Launcher build: uninstall that build first.

## Notes: what this has and hasn't been tested on

Unit tests cover the folder sizes, the audio-device choices and wording, the charge-time wording and the ordering of the recording mark; emulator tests show the recording mark appearing and going away and place the wide and tall folders. Not tried on a real device, so please check: connecting and disconnecting real headphones and Bluetooth audio (does the name show, and is nothing announced when the island first appears), a real screen recording (does the red mark appear and clear), and the time-to-full line on a charger.
