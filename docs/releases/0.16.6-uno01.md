# Uno Launcher 0.16.6-uno01

Uno now targets Pixel phones on GrapheneOS, with hardened networking, iOS-style continuous corners, a gentler shade-gesture opt-in, and a smarter feed reader.

## What's new

- **GrapheneOS-first.** The Pixel Fold (2023) on GrapheneOS is the primary design device; documentation no longer names a Samsung reference device.
- **The leading page always exists.** It shows Google Discover only where the Google app is installed and Window Extensions exist; otherwise (and whenever a configured feed is preferred) it is the news feed. With no feed configured it becomes an opt-in page offering the GrapheneOS announcements and release feeds — nothing is contacted until one is tapped.
- **Network hardening.** Feeds must be https; redirects are followed by hand, only within the same host and at most three hops, and an explicit network-security config refuses cleartext outright. A feed that moved servers asks you to add its new address instead of silently following it.
- **Feed reader improvements.** Untitled posts (Mastodon) get a headline built from their text, HTML is stripped from summaries, and Atom `xhtml` content is read instead of dropped.
- **iOS-style corners.** One four-step corner scale (12/18/24/32 dp plus capsule) replaces ad-hoc radii across every surface; app icons use Apple's 22.37% continuous-corner silhouette with an antialiased mask; settings switches use iOS colors. Panels keep circular-arc corners because the glass lens accepts only rounded rectangles.
- **Shade gestures are a one-time, easily declined opt-in.** The prompt explains what the accessibility service can and can't do, **No thanks** is remembered, and a declined swipe is silent. Help & setup still offers it.
- Fix unreadable dark text on the glass feed page.

## Notes

- If a feed you use stops updating after this release, it is likely serving http or redirecting across hosts; the troubleshooting notes explain how to confirm.
- This release is validated on emulators; treat it as a beta and report problems with your device model and Android version.

## Privacy

Uno has no account service, analytics, or automatic crash upload. Feeds are fetched only over https from the hosts you add; nothing is uploaded, and removing a feed removes its cache. See the [privacy notes](../PRIVACY.md).
