# Uno Launcher 0.23.0-uno01

Phase 2: the island can now follow you above other apps — opt-in, and built to GrapheneOS-grade touch safety.

## What's new

- **Island everywhere.** A new switch under **Customize launcher → Wallpaper & appearance** shows the island above other apps using Android's "display over other apps" permission. Home's own island steps aside, so there is never more than one.
- **Touch safety is the core design.** The overlay window is sized to *exactly* the island's current bounds — never full-screen — and is `NOT_FOCUSABLE` plus `NOT_TOUCH_MODAL`, so every touch outside the island passes straight through to the app beneath it. The window cannot intercept, cover, or fake anything else.
- **It never draws where it shouldn't.** The overlay is hidden on the lock screen and whenever the display is off (checked continuously), shrinks to 1×1 px when hidden, and is removed instantly if you revoke the permission. Turning the switch off removes the window immediately.
- **Explicit consent.** Enabling it opens an explainer first — what the permission does, what the island shows, and what it can't do — then Android's own overlay settings. On Android 13+, if the switch doesn't appear, a toast points you to the "allow restricted settings" step in Uno's app info.
- **Same island, shared state.** The overlay and Home share one island state (expansion, calls, media, timers, charging), so switching between Home and other apps is seamless.

## Verified

- 310 unit tests pass, including the overlay gating policy (permission + unlocked + screen-on).
- On-device window inspection confirms the overlay runs as `TYPE_APPLICATION_OVERLAY` with `NOT_FOCUSABLE | NOT_TOUCH_MODAL`, `layoutInDisplayCutoutMode=always`, and wrap-content sizing.
- No foreground service or persistent notification yet: the window itself keeps the process alive. If a device kills it, a foreground-service fallback is the known next step.

## Not yet confirmed on real hardware

- OEM behavior (Samsung/Pixel/GrapheneOS) for overlay windows, restricted-settings flows, and window survival over hours — please treat this as the Phase 2 beta.
- The overlay island's glass uses the flat fallback (it can't sample Home's backdrop from another window); a tint-only look for now.

## Privacy

The overlay shows only what the island already shows on Home — time, battery, calls, media, and your chosen tools. It reads nothing extra, stores nothing, and never draws on the lock screen. See the [privacy notes](../PRIVACY.md).
