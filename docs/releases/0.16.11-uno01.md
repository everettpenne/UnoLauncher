# Uno Launcher 0.16.11-uno01

The spacing-grid audit batch, the island/dock collision fix, and a reworked island size slider.

## What's new

- **Spacing-grid audit applied.** Dock and rail now sit 16 dp from the screen edge, bottom strips 8 dp up, the page-dots capsule uses 8 dp, the feed page uses 16/16/16/12 dp with 12 dp card gaps, the sheet uses 16 dp with 8 dp gaps, and the no-cutout island sits 8 dp below the status bar. All values now follow the scale documented in `docs/design.md`.
- **Island can't hit the dock anymore.** The expanded island's width is capped at `screenWidth − 2 × (dockWidth + 16 dp)`, so it can never reach the dock strip on cover-width displays — the collision flagged in the design audit is fixed.
- **Island size slider reworked.** The ranges are much wider (side slots 44–80 dp, hole surround 0–16 dp, minimum height 12–24 dp, expanded body 96–128 dp), so dragging the slider produces an unmistakable change on punch-hole devices — where the old ranges could be swallowed by the hole-hugging clamp. Two new unit tests pin the punch-hole behavior and the dock clearance.

## Notes

- The island size slider's wiring, persistence, and geometry were all verified end-to-end in code; the widened ranges are the visible part. If it still feels inert on your device after this release, grab a screenshot pair at 0% and 100% and share it — that will pin down any device-specific cutout clamping.
- This release is validated on emulators; treat it as a beta and report problems with your device model and Android version.
