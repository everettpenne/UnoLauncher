# Uno Launcher 0.92.0-uno01

The island lines its edges up with the gaps in the status bar, so it never cuts an icon in half.

## What's new

- Every edge of the island and its capsules falls in a gap between two status bar icons (measured on a Pixel 10a), so each icon is wholly covered or wholly clear, whatever is showing.
- The capsules are rounded rectangles: the left one covers exactly two notification icon slots, the right one as few slots as it needs.
- Privacy dots sit inside the island's right end.
- The clock's width is read from your time format, so a two-digit hour or a 24-hour clock still lands in the gaps.

Checked in unit tests and on the emulator, but only measured on one status bar: please check it on your phone.
