# Uno Launcher 0.120.0-uno01

Folders that open out of their tile and are square.

## What's changed

- **Folders**: the open panel grows out of the folder's tile and returns to it; it is square at every size.

## Install

Use **UnoLauncher-0.120.0-uno01-release.apk** from the release assets. Signed with the same key as 0.48.1 to 0.119.0-uno01, so it installs directly over them. Updating can switch off Notification access for Uno; turn it on again if the island loses track titles and artwork (Settings › Apps › Special app access › Notification access on GrapheneOS).
