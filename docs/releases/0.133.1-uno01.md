# Uno Launcher 0.133.1-uno01

Fixes for asking Qwen to do a task: results that end, an Undo that shows, and the right action.

## What's changed

Asking for an alarm in 0.133.0 gave a one-hour timer after a long think, an Undo that changed nothing on screen, two rows that never left, and an island line that never dismissed.

- **Alarms and timers asked for in ordinary words are answered at once**, by search itself, with no model: "set an alarm for 6am tomorrow", "wake me up at 6:30", "alarm for 7 tonight", "timer for an hour and a half", "20 minute timer". Before, only the short forms ("alarm 7am") were, and the rest went to Qwen for several seconds.
- **A plan that is not what you asked for asks first.** If your words name a kind of action (an alarm) and Qwen's plan is another kind (a timer), you are shown the plan with Do it and Cancel, even though nothing leaves the phone. A plan that matches still runs without a tap.
- **Undo works where you can see it.** The result changes to what the undo did ("Timer cancelled") and Undo goes away. If an undo fails it says so and can be tried again.
- **One result card.** What a task did is one card with the summary, Undo beside it when it can be taken back, and a cross to dismiss it. It was two full-width rows that looked like two buttons.
- **Results end.** A result goes when you dismiss it, type another question, or close search. If a task finishes after search is closed, the island says so for six seconds and then clears; a finished task you are looking at in search has no island line as well.
- "please …" and "hey, can you …" are treated as requests to do something, not questions.
- A timer's label that only repeats a time ("6am tomorrow") is not shown as its name.

Tasks are still off by default (**Let Qwen do tasks**, in Search settings) and need Uno Lab 0.3.9.

## Notes: what this has and hasn't been tested on

**On a Pixel 10a, with the test build (Uno Dev) and Uno Lab 0.3.9:**
- "set an alarm for 6am tomorrow" gave the instant "Alarm at 6:00 AM" row.
- A task Qwen planned ("please start a two minute countdown for my tea") showed the result card; Undo cancelled the timer and the card said so; the cross removed it; typing another question removed an old result; after closing search the island showed only the timer.

**In unit tests only (1,332 pass; lint clean):**
- A plan of the wrong kind being shown and asked about. The model could not be made to produce one on demand on the phone.
- The six-second island line for a task that finishes after search is closed.

**Not seen on a phone:** replying to a message from its notification, as in 0.133.0.
