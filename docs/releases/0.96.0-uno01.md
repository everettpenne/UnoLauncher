# Uno Launcher 0.96.0-uno01

One motion driver for the island, so interruptions carry on smoothly.

## What's new

- The island's body moves from one motion driver: when what it is heading for changes part-way, only what changes restarts, from where it is and how fast it is going, so a tap mid-morph, an activity ending mid-swap or a pull let go carries on smoothly.
- Every spring the island uses comes from one table, from its theme.

## Install

Use **UnoLauncher-0.96.0-uno01-release.apk** from the release assets. Signed with the same key as 0.48.1 to 0.95.0, so it installs directly over them.
