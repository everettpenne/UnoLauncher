# Uno Launcher 0.26.1-uno01

Fixes for 0.26.0: tap shadows that were still there, rectangles while dragging an icon, and widget-stack handling.

## What's fixed

- **Tap shadow.** The Material ripple was still being applied; it is now switched off properly everywhere.
- **Rectangles while moving an icon.** The shadow on the dragged icon and the framed boxes drawn over cells are gone. A soft square appears behind an app only when dropping would make a folder.
- **Widget stacks.** Touches that start on a stack's dots are no longer taken by the page swipes, and the fade between stacked widgets is back to a plain switch.
- **Drag to folder.** The middle zone of an app is a little wider. A test now drags an app onto another and checks a folder is made.

## Download and install

Use **UnoLauncher-0.26.1-uno01-release.apk** from the release assets. Signed with the same key as previous Uno releases, so it installs directly over 0.26.0. It still cannot install over a jakesgoodapps Duo Launcher build: uninstall that build first.

## Notes: what this has and hasn't been tested on

Drag tests pass on an emulator (8 of 8, including making a folder). Not checked on a phone: the ripple being gone, the stack rail, and drags from your own fingers. If dragging onto an app still does not make a folder, please note where you drag from and where you drop.
