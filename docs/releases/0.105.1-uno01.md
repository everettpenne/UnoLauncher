# Uno Launcher 0.105.1-uno01

A symmetric island, tuned on a Pixel 10a.

## What's changed

- **The island is exactly centred on the camera.** On Home with the side dock it was 2 to 5 px off and wider on one side; it is now a 16 mm pill centred on the camera and as tall as it. Over apps it stays symmetric while keeping clear of status bar icons.
- **The charge ring fills evenly up both sides** from the bottom, instead of clockwise from the top, and the lone battery glyph beside the camera is gone.

## Install

Use **UnoLauncher-0.105.1-uno01-release.apk** from the release assets. Signed with the same key as 0.48.1 to 0.105.0, so it installs directly over them.
