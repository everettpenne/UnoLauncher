# Uno Launcher 0.132.1-uno01

"Hello, Qwen" used to take seven seconds. Now it takes none.

## What's changed

- **Greetings, thanks, goodbyes and "who are you" are answered from a table.** No model, no facts read, no round trip: they are the same few words every time, so asking a 2B model for them only cost seconds. The reply appears as soon as you tap. Anything with more to it — "hello, what's the weather" — still goes to Qwen, because the whole message has to match, not just its start.
- **The assistant no longer asks the phone to do something before answering a question it could not act on.** Every greeting, thank-you and piece of chit-chat paid for an action turn that came back empty and then a second turn for the real answer. Now only a possible action pays for that extra turn: a command verb, "can you…", or the phone's own action named without a question — "wake me at 7", "I need a 20 minute timer".
- **Only the date and time ride along with every question.** Battery, alarm and Focus used to be sent with every answer, and were most of the prompt: about ninety tokens the model read before answering something like "why is the sky blue". They now come only when the question is about them, which takes about 1.5 s off the first token of every real answer.

## Notes: what this has and hasn't been tested on

The launcher's unit tests pass, including new ones for the small-talk table, for which requests are treated as commands, and for which facts a question asks for. **Not tested on a phone for this release:** the greeting's latency and the shorter prompt were reasoned from measurements taken on a Pixel 10a for 0.132.0 (2,398 ms prefill for 116 tokens, 6.8 tok/s generation), not re-measured here.

One behaviour changes deliberately: a command phrased without any word the assistant knows — "make it quieter" — is now answered in words instead of being performed. Commands that name their action, or start with a command verb, are unaffected.
