# Uno Launcher 0.126.0-uno01

A split that stretches and pops like rubber, an open island with Apple's margins, and menus and dialogs that all match.

## What's changed

- **Rubber split**: a second activity is pulled out of the island's own end. The end stretches into a tip, a waist forms and snaps, and the bubble pops into its place while the island recoils and jiggles. Going back plays it in reverse.
- **Equal margins**: the open island is as far from each side of the screen as from the top and centred on it, so with its concentric corner every edge runs parallel to the phone's.
- **One family of menus**: the app menu, the hold menu and the dropdowns open on the same spring and at the same width, with iOS's red for destructive actions.
- **Glass dialogs**: the shade-gesture, Discover and Island everywhere prompts are glass dialogs instead of system ones.
- **Home options**: the empty-space sheet's new title; What's New shows the version without its build suffix.

## Notes: what this has and hasn't been tested on

1,160 unit tests pass. On an emulator: the shade-gesture prompt (shown, kept across a recreation, declined) and the grid, settings and menu tests covering these changes; three of those fail the same way on 0.125.0-uno01. **Not seen:** the rubber split and the equal margins on screen (checked as frames drawn from the same maths); the Pixel 10a's own corner radius; any of it on a phone.
