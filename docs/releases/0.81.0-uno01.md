# Uno Launcher 0.81.0-uno01

Spotlight opens like a pill, not a rectangle.

## What's new

- **Corner morph.** The search panel's corners now animate with the emerge — a capsule while it is still pill-sized, easing to the 34dp panel corner as it grows — removing the brief "rounded rectangle" flash at the very start of opening and its mirror on close.

## Install

Use **UnoLauncher-0.81.0-uno01-release.apk** from the release assets. Signed with the same key as 0.48.1 to 0.80.0, so it installs directly over them.
