# Uno Launcher 0.16.4-uno01

Real refraction: the glass now bends the view behind it like the demo's full liquid effect, with a slider to set how much.

## What's new

- **Deeper lens refraction** — the lens effect now uses scaled refraction height and displacement with depth weighting, and engages chromatic aberration at high intensities for that color-fringed liquid look.
- **Refraction intensity slider** — under **Customize launcher → Wallpaper & appearance**, next to the Liquid glass switch. Default is 55%; crank it to 100% for the heavy bending seen in the backdrop demo, or pull it down toward a subtle frosted look.
- All glass surfaces follow the slider: dock, status rail, panels, folder view, and the feed page.

## Download and install

Use **UnoLauncher-0.16.4-uno01-release.apk** from the release assets. Signed with the same key as previous Uno releases, so it installs directly over 0.16.x. It still cannot install over a jakesgoodapps Duo Launcher build: uninstall that build first.

## Notes

- High refraction costs a little more GPU time per surface; the slider is your tradeoff dial, and the Liquid glass switch remains the off ramp.
- This release is validated on emulators; treat it as a beta and report problems with your device model and Android version.

## Privacy

Uno has no account service, analytics, or automatic crash upload. The internet permission exists only for fetching feed addresses you add. See the [privacy notes](../PRIVACY.md).
