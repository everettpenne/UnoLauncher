# Uno Launcher 0.132.2-uno01

Uno can be the phone's assistant — and answer from what's on the screen.

## What's changed

- **A question handed over by the system assistant opens search**, with what was on the screen at that moment available as one of the facts. Uno Lab takes the assistant role (which is what lets it read the screen); the launcher is what draws the search, as before.
- **"What's on your screen" is a fact like any other**: it comes only for a question that points at it — "summarise this page", "what does this say" — it is marked as a quote because another app wrote it, and it is **never** sent with a request that could turn into an action.
- The screen text is dropped when search closes, so it cannot turn up in a later question, and it is never stored.
- The facts list in Search › Local assistant now names the screen alongside messages and the clipboard.

## Notes: what this has and hasn't been tested on

Unit tests cover which questions ask for the screen, and that it never joins an action turn. **Not tested on a phone for this release**: the whole hand-off — the gesture, the session, the intent — needs Uno Lab 0.3.3 installed and the assistant role granted, and was not exercised before publishing.

Granting the role lets Uno Lab read the screen of whatever app is in front. That is the point of it, and it is worth knowing when you grant it.
