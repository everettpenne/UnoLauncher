# Uno Launcher 0.16.0-uno01

Uno Launcher is a foldable-first Android launcher based on [jakesgoodapps/DuoLauncher](https://github.com/jakesgoodapps/DuoLauncher) (MIT), with a right-side dock, native widgets, overlapping unfolded page pairs, and an optional private RSS/Atom news feed that fills the Discover slot without Google. Android 12 or later is required.

## Download and install

Use **UnoLauncher-0.16.0-uno01-release.apk** from the release assets (about 3 MiB). Open it on the phone, allow installation from that source if Android asks, and open Uno Launcher. The welcome screen lets you try Home, choose it as your default, or add a widget. All optional access can be skipped.

**This is the first Uno release and uses a new signing key.** It cannot install as an update over a jakesgoodapps Duo Launcher build: uninstall that build first (a layout backup can be saved from its **Customize launcher → Backup**, though widgets must be reconnected after restoring). Later Uno releases signed with this same key install over this one normally.

## Included in this release

- The Duo Launcher 0.15.0-beta01 feature set: right-side dock, Home status rail, alphabetical All apps, Google search with local app-search fallback, live Discover on compatible devices, fold-aware Home pairs, native Android widgets, folders, work profiles, local photo backgrounds, daylight appearance, and layout export/import.
- **Personal news feed:** add RSS 2.0 or Atom addresses in **Customize launcher → News feed**. Entries are fetched directly from those addresses, cached on this device, and shown in the Discover slot — automatically where Google's feed is unavailable, or always when you turn on **Use my feed instead of Discover**. Stories open in your browser.
- The leading feed slot works on devices without Window Extensions support, so the feed needs no Google app or account.
- Uno branding across the app, wallpapers, shade service, and documentation. The package identifier remains `com.jake.duolauncher`, inherited from the upstream project.

## Tested scope and limits

This release was validated on disposable Android 36 emulators: a 7.6″ Foldable profile (inner 1768×2208 and folded display regions, hinge postures) and a Pixel 10a-style profile (1080×2424 @ 420 dpi). Live feed fetching, parsing, caching, and opening were exercised on the emulators; the first-run welcome, shade-gesture prompt, and feed slot were exercised through the UI.

- 145 JVM unit tests pass, lint reports no errors, and the R8 release build assembles.
- No physical device has run this exact build yet. Please treat it as a beta and report problems with the Uno version, phone model, Android version, folded/unfolded state, and steps to reproduce.
- Discover depends on Google and device embedding support. Work widgets depend on administrator policy. Private Space, icon packs, notification dots, and nested/dock folders are not supported. Secure lock-screen replacement and hinge-driven cross-display animation are outside this release.

## Privacy

Uno has no account service, analytics, or automatic crash upload. The internet permission exists only for fetching feed addresses you add; nothing is uploaded, and removing a feed removes its cached entries. See the [privacy notes](../PRIVACY.md) for details on widget binding, shade gestures, location, and backups.
