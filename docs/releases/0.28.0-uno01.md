# Uno Launcher 0.28.0-uno01

Large folders, from HyperOS: a folder that spreads over several Home cells and launches its apps from its face.

## What's new

- **Large folder.** Widget picker, Uno Launcher, "Large folder". Tap it, choose "Choose folder apps", pick up to 24 apps and give it a name. Each app on the face opens with one tap.
- **Any size.** Resize it like a widget (tap it, Widget options, Resize). A bigger face shows more icons.

## Good to know

- You add apps through "Choose folder apps", not by dropping them on it.
- Apps you put in a large folder also stay wherever they already are on Home.
- A layout backup remembers the folder's place and size, not its apps or name.

## Download and install

Use **UnoLauncher-0.28.0-uno01-release.apk** from the release assets. Signed with the same key as previous Uno releases, so it installs directly over 0.27.0. It still cannot install over a jakesgoodapps Duo Launcher build: uninstall that build first.

## Notes: what this has and hasn't been tested on

A large folder shows its apps on Home and clears when removed, in an emulator test; the storage and size rules have unit tests. Not tried: tapping an app on the face, placing one through the picker, the name and app editor, resizing, and moving it between pages. Please try each on your phone.
