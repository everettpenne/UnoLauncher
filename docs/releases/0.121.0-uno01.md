# Uno Launcher 0.121.0-uno01

A notice when notification access is lost, and square widgets again on the side-dock layout.

## What's changed

- **Notification access**: if an update switches it off, Uno says so once and links to the setting.
- **Widgets**: 2 x 2 widgets on the side-dock layout's app rows are square again.

## Install

Use **UnoLauncher-0.121.0-uno01-release.apk** from the release assets. Signed with the same key as 0.48.1 to 0.120.0-uno01, so it installs directly over them. Updating can switch off Notification access for Uno; this version now tells you when it has.
