# Uno Launcher 0.101.0-uno01

The island can line up with your phone's real status bar icons.

## What's changed

- **Uno Launcher island alignment**, a new optional accessibility service. Turn it on in Android's Settings › Accessibility and the island keeps its edges in the real gaps between the status bar's icons on either side of the camera, on any phone, font or display size and whatever icons are showing. It never covers the clock.
- **What it can see:** only where the status bar's icons are on screen, from SystemUI's status bar window. It never reads their text or descriptions, never looks at another app's window, keeps only the latest positions in memory, takes no actions and sends nothing. It is separate from the shade gestures service, which still reads nothing.
- **Line up with the status bar** (Launcher settings › The island) shows whether it is on, with a button to the accessibility settings. With it off, the island uses the measured spacing and your hand guides, as before. The permission ledger lists the new service.

If Android says the setting is restricted, open Uno Launcher's App info and choose **Allow restricted settings** first.

## Notes: what this has and hasn't been tested on

Unit tests (992) and lint pass. On an Android 17 emulator the service read the status bar's clock, notification icon, signal, Wi-Fi and battery at their real positions. The emulator's emulated camera is in a corner, so the island lining up with those gaps was checked by unit tests, not on screen. **Not run on a real phone.**
