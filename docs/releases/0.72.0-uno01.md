# Uno Launcher 0.72.0-uno01

The island and the status bar stop competing, and a pull on the island is only a pull on the island.

## What's new

- **One owner per event, by rule.** A new, unit-tested arbiter (`IslandEventArbiter`) decides where every event shows: ongoing activities in the island; a new notification as the island's card (if you opted into titles/text) or the short name flash — but never while a card is already down, and not for three seconds after you opened the notification shade yourself. With the status rail on, it owns the battery level and the island drops its duplicate charging ring. The Android status bar is left alone: a launcher has no honest way to hide another app's icons, and Uno won't fake one.
- **A pull on the island is only a pull on the island.** A drag that starts on the pill no longer also fires the launcher's top-edge pull (which could open the shade, the control panel or search at the same time as your peek). The top-edge pull works as before everywhere else, and the peek still survives Android cancelling a drag at the very top of the screen.

## Notes: what this has and hasn't been tested on

Unit tests pass (including ten new arbiter tests: card vs flash vs silence, the shade cooldown, time/battery ownership, the pill hit-test), lint is clean, and the debug build runs on an Android 16 emulator. **It has not been run on a real phone**; the peek/shade interaction in particular wants a finger on a real status bar. See `docs/device-checklist.md`.
