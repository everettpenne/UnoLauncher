# Uno Launcher 0.29.1-uno01

A security release, in answer to an independent audit.

## What's fixed

- **The updater no longer installs on trust.** It refuses a release that has no published checksum, checks the checksum, and checks that the new APK is signed by the same key as the app you have, all before Android's installer is shown it.
- **Downloads are cut off at their size limit as they arrive**, and the updater only follows links to GitHub's own hosts.
- **Plainer, more accurate privacy wording.** Live Updates read the text of the promoted notification you see on the island (never chat messages); the shade-gesture consent now says the service also draws the island; dismissing that prompt by tapping outside is remembered; and PRIVACY.md says the island is drawn over banking and password apps, with the switch that turns it off.
- The updater's User-Agent shows the real version, and a stale keyboard comment is corrected.

## Not changed

A per-app "hide the island here" list would need to know which app is in front, which Uno does not and will not read. Turn "Island everywhere" off if you do not want the island over a given app.

## Notes: what this has and hasn't been tested on

Unit tests cover the redirect allowlist, the checksum and signer rules, and the size caps; an emulator test shows the platform reports the installed app's signing certificates for its own APK. The full update path (download, checksum, key check, install prompt) has not been run against a real release, so please try Customize, Updates, Check for updates on your phone when the next release appears and confirm it reaches Android's install prompt.
