# Uno Launcher 0.102.0-uno01

A centred island, Uno's own status bar for the iOS layout, and a way to tidy Android's.

## What's changed

- **The island is symmetric about the camera.** Both edges are chosen together, so it is centred on the camera and still never cuts a status bar icon in half, never covering the clock or the battery. It uses your status bar's real icons when island alignment is on, and the measured spacing otherwise.
- **Uno's status bar on Home** (iOS layout; Launcher settings › Home; off by default): the time left of the island, and alarm, Do Not Disturb, VPN, signal, Wi-Fi and battery right of it, as on an iPhone. Android's camera and microphone indicators are not drawn there; the island always shows its own.
- **Tidy the status bar** (Launcher settings › The island › Line up with the status bar): pick icons to hide and copy the adb command that hides them, with the command that undoes it.

Uno's status bar was checked on an Android 17 emulator (with a wide centred notch standing in for the camera).
