# Uno Launcher 0.91.0-uno01

The tuned island layout, an island that springs open for an app's name, and a fix for the top of the screen not taking touches.

## What's new

- The tuned layout is the default: the main island 15 dp wider, the left and right islands 10 dp wider and 2 dp closer in, three islands at most.
- When an app opens, the live activities tuck into the island, which springs 62 dp wider and 3 dp to the left, then returns with the activities when the name goes away.
- Fixed: the top of the screen could stop taking touches. The island's touch window was padded far beyond what it draws and swallowed touches meant for the app underneath; it is now exactly the island and its capsules.
- The Island debug page is only in debug builds.
