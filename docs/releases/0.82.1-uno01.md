# Uno Launcher 0.82.1-uno01

Concentric icons, for real.

## What's new

- App icons and artwork on the pill (and the detached capsules) are now circles sized a few pixels inside the pill's radius, centered, so they follow the island size and read as set into it. 0.82.0 shipped the leading/trailing restyle; this release actually ships the concentric-icon change its notes described.

## Install

Use **UnoLauncher-0.82.1-uno01-release.apk** from the release assets. Signed with the same key as 0.48.1 to 0.82.0, so it installs directly over them.
