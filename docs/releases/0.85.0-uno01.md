# Uno Launcher 0.85.0-uno01

Two fixes to the edge-page transition.

## What's new

- **The dock's glass slides with the dock.** The dock and status rail's glass surface now moves off-screen together with its icons, instead of staying put and floating over the feed and All apps.
- **Edge pages keep their margin.** The feed and All apps now sit with the same 16dp margin on both sides, not flush against the right edge.

## Install

Use **UnoLauncher-0.85.0-uno01-release.apk** from the release assets. Signed with the same key as 0.48.1 to 0.84.0, so it installs directly over them.
