# Uno Launcher 0.94.0-uno01

A tidier island over the status bar, and no more flying in at start-up.

## What's new

- The island's round ends no longer show a sliver of the signal icon: outer edges sit a little past the middle of their gap.
- The island no longer flies in from the middle of the screen when the launcher starts or the phone wakes; its window starts where it stays and is never animated into place.
- Music in a capsule no longer tints the island, and a timer in a capsule no longer rings it.

## Install

Use **UnoLauncher-0.94.0-uno01-release.apk** from the release assets. Signed with the same key as 0.48.1 to 0.93.0, so it installs directly over them.
