# Uno Launcher 0.88.0-uno01

Quieter capsules, and an Extra wide that follows the size slider.

## What's new

- The detached live-activity capsules are plain AMOLED black again, with no coloured rim or glow.
- Extra wide gives the pill the width of the 75% size setting, at the height you chose.
- Extra capsules show the activity's own symbol instead of an app's picture or album art; a navigation turn arrow stays.

## Install

Use **UnoLauncher-0.88.0-uno01-release.apk** from the release assets. Signed with the same key as 0.48.1 to 0.87.0, so it installs directly over them.
