# Uno Launcher 0.78.0-uno01

A quieter island, a feed that refreshes itself, and a launcher squared away.

## What's new

- **A quieter island.** The peek/morph fade no longer allocates a gradient each frame; action labels drop to icons before clipping at larger system fonts; long event titles get room instead of truncating; TalkBack announces charging.
- **The feed that refreshes itself.** Pull-to-refresh (the rubber band shows progress), a header spinner, stale-feed accent on "Updated", a Manage feeds button when everything is off, named failures when only some feeds fail, real 4.5:1 contrast, and off-main-thread sorting.
- **The launcher, squared away.** One press spring everywhere, a springy Spotlight close, folders that animate closed, grown touch targets, on-grid spacing, tokenized corners, and reduced-motion respected in the wiggle and battery ripple.
