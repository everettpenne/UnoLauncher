# Uno Launcher 0.130.0-uno01

Ask Qwen from search, answered on the phone.

## What's changed

- **Ask Qwen in search**: with [Uno Lab](https://github.com/everettpenne/UnoLab) 0.2.0 installed and **Local assistant** switched on in Launcher settings (it is off by default), search offers an **Ask Qwen** row for a question it can't answer itself.
- A request Qwen reads as one of Uno's actions (a timer, an alarm, the torch, Focus, a note, opening an app, a call or message, a web search) comes back as a row you tap to run; anything else comes back as a short answer in the results. Nothing is done on the model's word alone.
- The model runs in Uno Lab, never in the launcher. The question goes only to Uno Lab, which has no network access, and each app checks the other's signing key.
- Includes everything in 0.129.1-uno01.

## Install

Use **UnoLauncher-0.130.0-uno01-release.apk** from the release assets. Signed with the same key as 0.129.1-uno01, so it installs directly over it. For Ask Qwen, also install Uno Lab 0.2.0 and add the model (see Uno Lab's README).
