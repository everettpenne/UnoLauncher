# Uno Launcher 0.16.2-uno01

Experimental release: **liquid glass aesthetics**. The dock, the customization panel, and the feed page now blur and refract Home behind them — vibrancy, blur, and a lens effect, rendered locally with runtime shaders.

See the [0.16.0-uno01 notes](https://github.com/everettpenne/UnoLauncher/releases/tag/v0.16.0-uno01) for features, installation, and tested scope.

## What's new

- Liquid glass surfaces on the dock, customization panel, and feed page (Kyant0's [backdrop](https://github.com/Kyant0/AndroidLiquidGlass) library, Apache 2.0).
- A **Liquid glass** switch under **Customize launcher → Wallpaper & appearance**. Turning it off restores the previous flat glass look and saves battery.
- No new permissions or data use: the effect is drawn on-device.

## Download and install

Use **UnoLauncher-0.16.2-uno01-release.apk** from the release assets (about 3 MiB). Signed with the same key as previous Uno releases, so it installs directly over 0.16.x. It still cannot install over a jakesgoodapps Duo Launcher build: uninstall that build first.

## Notes

- If the glass effect ever misbehaves on a specific device, turn the switch off — Home falls back to the flat look instantly.
- The effect relies on Android runtime shaders (available since Android 12, Uno's minimum) and is not yet broadly device-tested.
- This release is validated on emulators; treat it as a beta and report problems with your device model and Android version.

## Privacy

Uno has no account service, analytics, or automatic crash upload. The internet permission exists only for fetching feed addresses you add. See the [privacy notes](../PRIVACY.md).
