# Uno Launcher 0.115.0-uno01

iOS 26 widget shapes, and widgets that scale with the icons.

## What's changed

- **Widget shape**: a 26 dp continuous corner, as iOS 26's widgets.
- **Widget size** follows Icon Size: it grows or shrinks with the icons beside it and stays aligned to them.

## Install

Use **UnoLauncher-0.115.0-uno01-release.apk** from the release assets. Signed with the same key as 0.48.1 to 0.114.1-uno01, so it installs directly over them. Updating can switch off Notification access for Uno; turn it on again if the island loses track titles and artwork (Settings › Apps › Special app access › Notification access on GrapheneOS).

## Notes: what this has and hasn't been tested on

The corner was seen on an Android 36 emulator (card widgets); unit tests and lint pass. **Not seen on the Pixel 10a:** the shape, Glass-style widgets, or widgets at 60 or 125 percent icon size.
