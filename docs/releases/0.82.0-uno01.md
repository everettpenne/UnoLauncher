# Uno Launcher 0.82.0-uno01

The island reads like Apple's.

## What's new

- **Leading attached, trailing detached.** With two live activities the main pill keeps the leading one (attached to the camera); the second becomes its own detached black capsule to the right, with a small gap and a hairline rim. Activities beyond two pop out as more of the same capsules — one coherent row, not a cramped pill and plain circles. Sideways flick still swaps which is leading; tapping a capsule brings it forward.
- **Concentric icons.** App icons and artwork on the pill are circles sized a few pixels inside the pill's radius, centered, so they follow the island size and read as set into it.

## Install

Use **UnoLauncher-0.82.0-uno01-release.apk** from the release assets. Signed with the same key as 0.48.1 to 0.81.0, so it installs directly over them.
