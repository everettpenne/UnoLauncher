# Uno Launcher 0.98.0-uno01

Uno Keyboard, rebuilt: liquid glass, swipe typing, smarter autocorrect and predictions that learn on the phone, and Fossify Keyboard's features.

## What's new

- A liquid-glass keyboard that blurs the app behind it where the phone allows, with a springy press. **Key style › Classic** keeps the flat 0.97 look with every new feature.
- A live keyboard at the top of its settings shows each change and can be typed on.
- Swipe typing; autocorrect that uses where each key was touched and splits run-together words; one-tap undo of a correction.
- Predictions and completions that learn your words, kept in no-backup storage on the phone. Never learned in password, email, address or number fields or incognito tabs; turn it off, edit your words, or forget everything in Settings.
- Emoji suggestions, emoji search and skin tones.
- Clipboard history (an hour; pinned clips kept; sensitive copies skipped), a text-editing panel, a voice-typing button, autofill chips from your password manager.
- 17 layouts, keyboard height, key sounds, optional emoji key and key magnifier, digits on the top row's long-press.
- Haptic feels (Soft, Crisp, Firm) and new cues.

## Notes: what this has and hasn't been tested on

Unit tests (including swipe accuracy on generated paths and the keyboard privacy rules), the keyboard's instrumented tests and lint pass. Typing, autocorrect, swiping, the blur, the tools and both key styles were tried on an Android 17 emulator. **Not run on a real phone**, so the haptic feels and real-finger swiping are untried. Autofill chips and the non-English layouts were not exercised. See `docs/device-checklist.md`.
