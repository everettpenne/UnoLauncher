# Uno Launcher 0.30.0-uno01

A library of nine new widgets, backup of their contents, and a round of tidying.

## What's new

In the widget picker, under **Uno widgets** (no permissions, nothing sent anywhere):

- **Battery**: a ring for the charge, and time to full while charging.
- **Month**: this month's calendar with today marked.
- **Day, month and year**: how far through each you are.
- **Moon phase**: today's moon.
- **Countdown**: days to or since a date you choose.
- **Note**: a short note kept on the phone.
- **Counter**: tap to add one.
- **Timers**: one tap starts a 5, 10, 25 or 45 minute timer in the island.
- **Sunrise and sunset**: for the place you set in Appearance.

Backups now include notes, counters, countdowns and large folders' apps.

## Tidying

Removed an unused old settings panel, fixed arrows and the delete key for right-to-left languages, and brought the Help page and the guides in line with the grouped settings and the swipe-up gesture.

## Download and install

Use **UnoLauncher-0.30.0-uno01-release.apk** from the release assets. Signed with the same key as previous Uno releases, so it installs directly over 0.29.1. It still cannot install over a jakesgoodapps Duo Launcher build: uninstall that build first.

## Notes: what this has and hasn't been tested on

Emulator tests place all nine widgets and check they draw, that a counter tap counts and that a note is forgotten with its widget; screenshots were looked at and the layout adjusted. Unit tests cover the calendar, progress, moon, countdown and sun rules and the backup. Not tried on a real phone: the date picker in the countdown, the note and name editors, timers starting from the widget, the sunrise card with a real place set, and restoring a backup that carries widget notes. Moon phase uses the mean cycle, so it can be a few hours off the true phase.
