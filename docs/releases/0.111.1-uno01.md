# Uno Launcher 0.111.1-uno01

Fixes for the island's pause and glow, hold menus for widgets and folders, a widget gallery that opens an app at a time, and a softer App Library.

## What's changed

- **Island**: pause now stops players that ignore it; the glow over the camera fades smoothly (a vertical line is gone); the small pill has no bright edge; a charging pill opens a battery card on a long press; swaps blur; a finished timer bursts.
- **Hold menus**: widgets and folders on Home get a small frosted menu, dock apps get the app menu; the dim reaches the whole window.
- **App Library and feed**: a blurred wallpaper behind translucent glass cards; flatter, more modern app icons.
- **Widget gallery**: an Apps list that opens each app's widgets as pages with an Add widget button; a held preview still drags onto Home.
- **Photos widget** supports Android 14's selected-photos access.

## Install

Use **UnoLauncher-0.111.1-uno01-release.apk** from the release assets. Signed with the same key as 0.48.1 to 0.111.0, so it installs directly over them. Updating can switch off Notification access for Uno; if the island loses track titles and artwork, turn it on again (Settings › Apps › Special app access › Notification access on GrapheneOS).

## Notes: what this has and hasn't been tested on

Run on a Pixel 10a (GrapheneOS): the pause fix with a real player, the smooth glow, the hold menu on a widget and on an app, the widget gallery's Apps list and an app's pager, the App Library over the blurred wallpaper, the charging card (with the phone reporting a fake charge level), and the full instrumented suite (the failures match 0.110.0, apart from one test that was updated). **Not tried with real data:** the call, Live Update, download and navigation cards; the folder hold menu; a populated dock's hold menu; the blur on a pill swap.
