# Uno Launcher 0.110.0-uno01

A welcome sheet that turns the island on, a preview that plays by itself, and an optional camera and microphone log.

## What's changed

- **Welcome sheet**: a "Wake up the island" group shows whether Notification access and Island alignment are on, and opens Android's page for each.
- **Island settings**: the preview tours music, a Live Update, a message and the open island on its own; with notification access off, the Notifications group says so and has a Turn On button.
- **Camera & Mic log** (off by default): when the camera, microphone or screen recording was in use and for how long, on this phone only, with no app named.
- **Fixes**: the Home preview in settings now has a name for screen readers.

## Install

Use **UnoLauncher-0.110.0-uno01-release.apk** from the release assets. Signed with the same key as 0.48.1 to 0.109.0, so it installs directly over them.

## Notes: what this has and hasn't been tested on

Run on a Pixel 10a (GrapheneOS): the welcome sheet's new group and its button to Android's notification access page, and the preview touring on its own. The 261 instrumented tests were run there too: the 20 that fail also fail on 0.104.2 (they are written for an emulator or a foldable), so none is new. The Camera & Mic log is unit-tested but was not tried with real camera or microphone use.
