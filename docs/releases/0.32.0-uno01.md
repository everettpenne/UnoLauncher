# Uno Launcher 0.32.0-uno01

More for the island, drop-to-add for large folders, and a written list of what still needs fixing.

## What's new

- **The island above other apps has buttons.** Search, Feed and Customize now open Uno on the right screen from the island over any app. (The island cannot take typing itself; Uno's own search box does.)
- **Quick launch.** The open island shows the apps you chose under *Control panel & Focus, Shortcuts in the panel*, one tap each. There is a switch for it in *Dynamic island* settings.
- **More tools.** Long-press the island for Android's Internet and Volume panels beside the timer, stopwatch and flashlight.
- **End a call** from the island's call card.
- **Drop an app onto a large folder** to put it inside.

## Known problems

Three reported problems are **not fixed** in this release and are written up in `docs/future-fixes.md`: the island's typed search is not where you can find it over other apps (the buttons above are the first step), "Use device location" never completes, and entering a place by hand seems to do nothing. The same file lists the features that have never been run on a real phone.

## Download and install

Use **UnoLauncher-0.32.0-uno01-release.apk** from the release assets. Signed with the same key as previous Uno releases, so it installs directly over 0.31.0. It still cannot install over a jakesgoodapps Duo Launcher build: uninstall that build first.

## Notes: what this has and hasn't been tested on

Emulator tests show the shortcut strip, the End button and the drop onto a large folder; unit tests cover the shortcut picking and which call action is hang-up. Not tried on a phone: the overlay buttons opening Uno from over another app (it relies on Android letting the accessibility overlay start an activity, as the notification peek's app icon already does), the Internet and Volume panels from the tools face, and End on a real call.
