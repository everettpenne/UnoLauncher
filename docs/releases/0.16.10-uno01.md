# Uno Launcher 0.16.10-uno01

An island size slider and an in-launcher Updates page with auto-update and version selection.

## What's new

- **Island size slider.** Under the Dynamic island switch, **Island size** runs from Compact to Large: the capsule's height, the padding around the camera hole, and the side slots all scale with it. The midpoint matches the previous fixed size, so a too-tall island on real hardware can now be dialed down (or up).
- **Updates page.** New **Customize launcher → Updates**:
  - **Check for updates** lists the latest Uno releases from GitHub.
  - Install **any** version, including older ones — Android's installer handles same-signer downgrades (it may clear saved layout data the older version can't read; the page says so).
  - **Auto-update** checks every few hours, downloads the newest release, verifies it against the release's published SHA256SUMS, and opens Android's install prompt. Android always asks you to confirm — Uno can't and won't install silently.
- The update downloader is https-only and reports the per-app network toggle as an error, like the feed reader.

## Download and install

Use **UnoLauncher-0.16.10-uno01-release.apk** from the release assets. Signed with the same key as previous Uno releases, so it installs directly over 0.16.x. It still cannot install over a jakesgoodapps Duo Launcher build: uninstall that build first.

## Notes

- Auto-update uses unauthenticated GitHub API calls (rate-limited per IP), a few per day at most.
- Installing from the Updates page needs Android's "install unknown apps" permission for Uno, the same one you granted to sideload it.
- This release is validated on emulators; treat it as a beta and report problems with your device model and Android version.

## Privacy

Uno has no account service, analytics, or automatic crash upload. The Updates page talks only to the Uno Launcher GitHub repository, downloads only Uno's own releases, and verifies checksums before anything can be installed. See the [privacy notes](../PRIVACY.md).
