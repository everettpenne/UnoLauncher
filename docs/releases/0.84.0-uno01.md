# Uno Launcher 0.84.0-uno01

The dock knows its place, and the island icon breathes.

## What's new

- **Edge-page transitions.** Between home pages the dock and status rail stay pinned. Swipe into the feed (left) or All apps (right) and they slide off-screen with the home page, while the feed and All apps expand to the width the dock vacated — a 1:1, interruptible slide driven by the pager's own offset.
- **A wider icon border.** The island's app icon / artwork circle is a little smaller, so it sits inside a wider pill border.

## Install

Use **UnoLauncher-0.84.0-uno01-release.apk** from the release assets. Signed with the same key as 0.48.1 to 0.83.0, so it installs directly over them.

## Notes: what this has and hasn't been tested on

Unit tests pass (7 new edge-shift tests), lint is clean, and the debug build runs on an Android 16 emulator. **Not run on a real phone** — the edge slide is exactly the kind of motion to feel with a finger. See `docs/device-checklist.md`.
