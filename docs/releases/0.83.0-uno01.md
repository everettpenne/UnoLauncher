# Uno Launcher 0.83.0-uno01

One type scale, everywhere, and a wide island whose icon sits in its end.

## What's new

- **Visual coherence.** The All apps list, Spotlight rows, the status rail, every widget and the settings now share the `UnoType` HIG scale, consistent section headers and label colors, and the corner tokens — and the last Material `surfaceVariant` slabs are gone. The launcher reads as one piece of glass instead of a family of separately-tuned surfaces.
- **Wide-island icon placement.** When the pill is wide, the app icon or artwork sits concentrically with the pill's rounded end, a few pixels inside it.

## Install

Use **UnoLauncher-0.83.0-uno01-release.apk** from the release assets. Signed with the same key as 0.48.1 to 0.82.1, so it installs directly over them.
