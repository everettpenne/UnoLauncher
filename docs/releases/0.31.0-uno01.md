# Uno Launcher 0.31.0-uno01

Fixes and polish: sunrise from your location, glass folders, keyboard tweaks and a search field in the island.

## What's new

- **Sunrise and sunset from your location now works on GrapheneOS.** It uses the phone's GPS when there is no network location service, asks for approximate and precise location together (either is fine) and keeps the place rounded to about 11 km.
- **Folders on Home look like the dock**: glassy tint and a bright rim.
- **Keyboard:** after typing a symbol such as an apostrophe from the numbers page it goes back to the letters, and there is more room under the bottom row so the Return key is further from Android's keyboard-switch button.
- **Island search field.** Open the island, type in "Search the web" and press Enter: your browser opens on the results with your words already searched. Enter in the full search opens the top app, or searches the web.
- **Widget placement preview** is drawn from the same origin as the widget itself.

## Download and install

Use **UnoLauncher-0.31.0-uno01-release.apk** from the release assets. Signed with the same key as previous Uno releases, so it installs directly over 0.30.0. It still cannot install over a jakesgoodapps Duo Launcher build: uninstall that build first.

## Notes: what this has and hasn't been tested on

The island search field, the preview alignment and the drag and folder tests were run on an emulator; the rules for location and the keyboard are unit tested. **Not tried on a phone**: the location fix itself (please try Use device location, outdoors if GPS is all you have), the new Return key spacing, the keyboard returning to letters, and the folder glass look. The widget placement preview matched exactly on the emulator, so if it still looks off on your phone, please send a screenshot of the preview and of the placed widget.
