# Uno Launcher 0.23.2-uno01

The everywhere-island hugs the camera cutout again.

## What was wrong

Overlay windows don't reliably receive the display cutout in their own window insets, so the island fell through to the "no cutout" layout — status bar plus a gap — leaving the half-inch of space you saw below the camera.

## What's fixed

The overlay now builds the island's environment from the display itself instead of its window insets: real display metrics for the size, **`Display.getCutout()`** for the camera hole (the public API, authoritative regardless of window type), and the system status-bar height for the no-cutout fallback. The environment refreshes on every configuration change, so rotation and folding re-anchor correctly.

**Verified on-device with an emulated punch hole:** the overlay window measures and positions itself to wrap the hole exactly — the same geometry your Home island has always used.

## Notes

- The exact hug around your phone's real punch hole deserves a look; the geometry constants are unchanged from Home, so any remaining gap would be device-specific and a one-line tune.
- This release is validated on emulators; treat it as a beta.

## Privacy

Unchanged: the overlay shows only what the island already shows on Home, stores nothing, and never draws on the lock screen. See the [privacy notes](../PRIVACY.md).
