# Uno Launcher 0.104.1-uno01

A fix for the island's resting width.

## What's changed

- **The island at rest is a pill about 13.5 mm wide** (the leaked width of the iPhone 18 Pro's island), on Home and over other apps, on either layout. In 0.104.0 it could shrink to a ring round the camera, about 7 mm wide, especially with Uno's accessibility service on. As before, it grows a little where needed so it never cuts a status bar icon in half.

## Install

Use **UnoLauncher-0.104.1-uno01-release.apk** from the release assets. Signed with the same key as 0.48.1 to 0.104.0, so it installs directly over them.
