# Uno Launcher 0.132.0-uno01

Ask Qwen keeps working while you get on with something else.

## What's changed

- **Ask, then put the phone down.** A question no longer keeps search open. Tapping **Ask Qwen** hands it to Uno Lab and the panel can be closed at once; the answer is waiting when search is opened again.
- **The island shows the turn.** While the model works the pill reads **Thinking…**; when the answer is ready it reads **Ready**. Tapping the pill opens search on that answer.
- **The card clears once it has been read.** Closing search after the answer has been shown takes the card off the island, so it is not left behind for the rest of the day.
- **Closing search no longer cancels the answer.** The panel's own connection to Uno Lab used to cancel whatever Uno Lab was answering, which left the turn stuck at "Thinking…" for ever; only a client that asked is now allowed to cancel.
- Answers are quicker: Uno Lab 0.3.2 restores its decoded system prompt from disk and skips a model round trip for questions.
- Needs Uno Lab 0.3.2 for the island's card and the quicker answers; older Uno Lab still answers in search.
