# Uno Launcher 0.119.0-uno01

Consistent loading, empty and error states, and two island card fixes.

## What's changed

- **States**: the App Library and the feed show one design for empty and failed states, with placeholder rows while loading.
- **Island**: a card opens for an activity with no buttons; the navigation card is full width.

## Install

Use **UnoLauncher-0.119.0-uno01-release.apk** from the release assets. Signed with the same key as 0.48.1 to 0.118.0-uno01, so it installs directly over them. Updating can switch off Notification access for Uno; turn it on again if the island loses track titles and artwork (Settings › Apps › Special app access › Notification access on GrapheneOS).
