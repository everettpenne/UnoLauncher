# Uno Launcher 0.112.0-uno01

Widgets that move icons out of the way, widgets aligned to the icons, an Icon Size slider and Auto dark icons.

## What's changed

- **Widgets**: put one down on apps and they move aside to the next free cells (onto the next page if needed), as on iOS; a widget's top and bottom line up with the icons beside it, and 2 x 2 widgets are exactly square.
- **Icons**: Icon Size scales the icons inside the same grid (both layouts); a new Auto style follows light and dark.
- **iPhone layout**: the App Library and the feed reach the bottom.

## Install

Use **UnoLauncher-0.112.0-uno01-release.apk** from the release assets. Signed with the same key as 0.48.1 to 0.111.1, so it installs directly over them. Updating can switch off Notification access for Uno; turn it on again if the island loses track titles and artwork (Settings › Apps › Special app access › Notification access on GrapheneOS).
