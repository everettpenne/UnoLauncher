# Uno Launcher 0.117.0-uno01

Folders in the iOS 26 style.

## What's changed

- **Folders**: a frosted glass tile with nine small icons, evenly spaced, as iOS 26's.

## Install

Use **UnoLauncher-0.117.0-uno01-release.apk** from the release assets. Signed with the same key as 0.48.1 to 0.116.0-uno01, so it installs directly over them. Updating can switch off Notification access for Uno; turn it on again if the island loses track titles and artwork (Settings › Apps › Special app access › Notification access on GrapheneOS).
