# Uno Launcher 0.132.4-uno01

Fixes a crash when the assistant gesture opened search over an app.

## What's fixed

0.132.3 opened the floating search panel already visible, which focuses its text field on the very first frame — before the panel has been placed. Compose then threw:

```text
java.lang.IllegalStateException: Expected BringIntoViewRequester to not be used before parents are placed.
```

Home's search never hit this because it starts closed and opens after layout. The floating window now becomes visible on the frame *after* the first layout, so focus and the keyboard arrive once there is something to focus, and no scroll-to-caret can run before the node exists. Nothing else about the panel changed.

## Notes: what this has and hasn't been tested on

The fix is one deferred state change in `AssistActivity`; the unit suites pass and the release builds. **Not tested on a phone**: whether one frame is enough in practice, and whether the panel then appears over the app as intended. The crash was reported on a Pixel 10a running Android 17 build `CP3A.261005.005`.
