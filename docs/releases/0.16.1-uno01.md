# Uno Launcher 0.16.1-uno01

Maintenance release: first fully automated CI release. The app is unchanged from 0.16.0-uno01; this build exercises the new release pipeline, which builds, signs, and publishes releases whenever a version tag is pushed.

See the [0.16.0-uno01 notes](https://github.com/everettpenne/UnoLauncher/releases/tag/v0.16.0-uno01) for features, installation, and tested scope.

## Download and install

Use **UnoLauncher-0.16.1-uno01-release.apk** from the release assets (about 3 MiB). Open it on the phone, allow installation from that source if Android asks, and open Uno Launcher.

This release is signed with the same key as 0.16.0-uno01, so it installs directly over it. It still cannot install over a jakesgoodapps Duo Launcher build: uninstall that build first.

## Privacy

Uno has no account service, analytics, or automatic crash upload. The internet permission exists only for fetching feed addresses you add. See the [privacy notes](../PRIVACY.md).
