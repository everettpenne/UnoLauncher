# Uno Launcher 0.113.0-uno01

A new app icon.

## What's changed

- **App icon**: the island over a grid of app tiles on a teal gradient, in the iOS 26 style; an adaptive icon with a themed version (the old icon was a flat square).

## Install

Use **UnoLauncher-0.113.0-uno01-release.apk** from the release assets. Signed with the same key as 0.48.1 to 0.112.0, so it installs directly over them. Updating can switch off Notification access for Uno; turn it on again if the island loses track titles and artwork (Settings › Apps › Special app access › Notification access on GrapheneOS).

## Notes: what this has and hasn't been tested on

The icon was drawn and checked as renders on a computer; the suite's other apps' icons were seen in an emulator's launcher (Baliset's), and Uno's own was not looked at on a device. Nothing else changed from 0.112.0, which was itself only checked on an emulator.
