# Uno Launcher 0.127.1-uno01

Wallpaper folders, a Spotlight that closes the way it opens, and an open island that rounds like the screen.

## What's changed

- **Wallpaper folders**: Appearance › Folders › Add Folder picks a folder with Android's folder picker; its pictures appear as tiles, and tapping one opens it in the wallpaper editor. Uno reads only the folders you add, needs no storage permission, and gives a folder's access back when you remove it.
- **Spotlight closes in reverse**: its contents shrink, fade and rise back toward the island, bottom rows first, before the outline draws in.
- **The open island rounds like the screen**: the open panel, peeks, cards and search take the display's own corner radius.
- Includes everything in 0.127.0-uno01: smoother paging, My feed in place of Google Discover, and an island that steps aside.
