# Uno Launcher 0.104.2-uno01

The island's resting size, refined.

## What's changed

- **The island at rest is a pill about 16 mm wide, as tall as the camera.** On punch-hole phones like the Pixel 10a it was much taller than the camera cutout; it now hugs the hole. As before, it grows a little where needed so it never cuts a status bar icon in half.
- **The island settings preview matches the real island.** It no longer draws a tall, chunky pill with undersized status bar icons.

## Install

Use **UnoLauncher-0.104.2-uno01-release.apk** from the release assets. Signed with the same key as 0.48.1 to 0.104.1, so it installs directly over them.
