# Uno Launcher 0.27.0-uno01

Two things borrowed from HyperOS: choosing which apps can use the island, and a music bar you can scrub.

## What's new

- **Apps that can use the island.** Customize, Dynamic island, "Apps that can use the island". Every app is linked until you switch it off; a switched-off app's Live Updates and notification peeks stay out of the island.
- **Seekable music progress.** The open island's music card now has a position bar. Tap to jump, drag to scrub. It appears when the player reports a track length.

## From HyperOS, not done

Folder sizes (2x1, 1x2, large folders you launch from without opening) and a 5x8 home grid need bigger changes to the home grid and drag model, so they are saved for their own release. The lock-screen features belong to the system, not a launcher.

## Download and install

Use **UnoLauncher-0.27.0-uno01-release.apk** from the release assets. Signed with the same key as previous Uno releases, so it installs directly over 0.26.1. It still cannot install over a jakesgoodapps Duo Launcher build: uninstall that build first.

## Notes: what this has and hasn't been tested on

Unit tests cover the app-link rules and the progress and seek maths, and the island's instrumented tests were rerun after the gesture change. Not tried with a real player: the seek bar (does a drag scrub smoothly, does your player honour seeking, does the bar follow the track), and the per-app list with real Live Updates and notifications. Notification access must be on.
