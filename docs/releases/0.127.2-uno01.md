# Uno Launcher 0.127.2-uno01

A slower, smoother island that leaves Home still behind it, smoother search, and a charging ring that peeks out from behind the island.

## What's changed

- **A slower, smoother island**: it opens and closes 30 % more slowly, and search grows out of it at the same tempo.
- **Home stays still behind the island**: with the accessibility service on, the status bar stays up while the island is open, so Home no longer redraws behind it.
- **Smoother search**: the island's window no longer resizes as search opens and closes.
- **The charging ring peeks out from behind the island**, following its squircle edge.
- Includes everything in 0.127.1-uno01: wallpaper folders, Spotlight closing in reverse, and screen-round island corners.
