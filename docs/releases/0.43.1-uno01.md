# Uno Launcher 0.43.1-uno01

Fixes the Photos widget, which showed nothing after you chose photos.

## What's new

- **Photos widget now shows your photos.** Choosing photos saved them but the widget never drew any: the code that reads a picture's size treated Android's normal "no bitmap returned while measuring" answer as a failure, so every picture was rejected. Fixed, with an emulator test that puts a real image in the widget and checks it is drawn.

## Install

Use **UnoLauncher-0.43.1-uno01-release.apk** from the release assets. Signed with the same key as previous Uno releases, so it installs directly over 0.43.0. It still cannot install over a jakesgoodapps Duo Launcher build: uninstall that build first.

Unit tests, lint, a release build and the new emulator test were run. The test uses a photo from the emulator's own media store; a photo from your phone's picker should behave the same, but please say if it does not.
