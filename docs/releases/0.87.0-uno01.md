# Uno Launcher 0.87.0-uno01

Several live activities, handled better.

## What's new

- The activity you bring to the front stays there while others start and end; a flick steps through all of them.
- Capsules glide to their new places, press down under your finger, and have clearer accessibility labels.
- The extra capsules carry a wash and a breathing rim in their activity's colour.

## Install

Use **UnoLauncher-0.87.0-uno01-release.apk** from the release assets. Signed with the same key as 0.48.1 to 0.86.0, so it installs directly over them.
