# Uno Launcher 0.22.1-uno01

A crash fix for the Control panel & extras page.

## What changed

- **Fixed: launcher crashed opening Customize → Control panel & extras** on Android 14 and newer. The page read two IME settings that Android restricts to apps targeting SDK 33 or lower — `enabled_input_methods` and `default_input_method` — and Android threw a `SecurityException` (`Settings key: <enabled_input_methods> is only readable to apps with targetSdkVersion lower than or equal to: 33`).
- The enabled-keyboard list now comes from the public `InputMethodManager` API, which is unrestricted and equivalent.
- Android 14+ has no public replacement for the selected-keyboard setting, so on those devices the page says Uno Keyboard is enabled and keeps the **Switch to Uno Keyboard** button (it opens Android's own picker) instead of guessing. On Android 12–13 the previous "is selected" status still works exactly as before.
- The keyboard service's hard-keyboard setting read got the same defensive guard.
