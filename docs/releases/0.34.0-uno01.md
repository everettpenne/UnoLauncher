# Uno Launcher 0.34.0-uno01

The island wears app colours, can stay wide, and runs smoother; dragging and the clock cards do less work.

## What's new

- **App colour on the island.** Notification cards, event flashes and downloads take the colour of the app's icon.
- **Permanent wide island.** A switch in the island settings keeps the pill wide over other apps instead of shrinking to a ring.
- **Smoother island.** The stutter when it expanded with app icons showing came from loading the icons as it opened; they are now loaded ahead of time. The island also stops asking the window manager to resize its touch area on every animation frame.
- **Smoother dragging and less idle work.** Dragging an app no longer redraws the whole launcher on each touch event, the clock cards tick once a minute instead of every second, and bursts of notifications are handled once.
- **A baseline profile** so Android compiles the app ahead of time.

## Download and install

Use **UnoLauncher-0.34.0-uno01-release.apk** from the release assets. Signed with the same key as previous Uno releases, so it installs directly over 0.33.0. It still cannot install over a jakesgoodapps Duo Launcher build: uninstall that build first.

## Notes: what this has and hasn't been tested on

The island, dragging, folders, widgets and settings emulator suites were re-run on this build, and unit tests cover the new helpers. **Nothing here has been timed on a phone**, so please say whether opening the island with icons showing, dragging an app and scrolling feel smoother. The colour comes from each app's icon, so a grey or white icon gives none. The permanent wide island covers the status bar icons beside the camera by design.
