# Uno Launcher 0.48.1-uno01

The same app as 0.48.0, signed with a new key. Uninstall the old version first.

## What's new

- **The app is now signed with a new key.** The password for the old signing key was lost, so a new key was made and its password stored safely. Android will not install an update signed with a different key, so **this release does not install over 0.47.0 or 0.48.0: uninstall Uno first.** Before you do, export a layout backup from Settings (Backup) and restore it afterwards. Future releases use this key, so this is a one-time step.
- No other changes: the 0.48.0 features (several Home pages, the Spotlight revamp, exact widget resize rows) are all here.

## Install

Use **UnoLauncher-0.48.1-uno01-release.apk** from the release assets. **Uninstall Uno 0.47.0 or 0.48.0 first** (back up your layout in Settings), because the signing key changed. It also cannot install over a jakesgoodapps Duo Launcher build.

## Notes: what this has and hasn't been tested on

Unit tests, lint and the public-source check were run for 0.48.0, and this release changes only the version and the signing key. **Nothing has been seen on a phone.** The CI release checks that the APK's certificate matches the fingerprint above.
