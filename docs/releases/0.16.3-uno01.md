# Uno Launcher 0.16.3-uno01

Liquid glass grows up: the status rail and folder panel join the dock, panels, and feed page as glass surfaces; icons get a springy press glow; and the glass tint follows your wallpaper.

## What's new

- **Glass status rail and folder panel** — the vertical status rail sits in a soft glass pill, and folder panels blur and refract Home behind them.
- **Press glows** — dock, Home, and folder icons spring down slightly and bloom with a soft white light on press, driven by the existing press state (no extra gesture handling, so drag-and-drop is untouched).
- **Wallpaper-tinted glass** — with a photo background, the glass surfaces blend the photo's muted palette color into the theme tint. The drawn dunes keep the theme's own tint.
- Everything stays behind the **Liquid glass** switch under **Customize launcher → Wallpaper & appearance**.

## Download and install

Use **UnoLauncher-0.16.3-uno01-release.apk** from the release assets. Signed with the same key as previous Uno releases, so it installs directly over 0.16.x. It still cannot install over a jakesgoodapps Duo Launcher build: uninstall that build first.

## Notes

- If anything misbehaves on a specific device, turn the liquid glass switch off — everything falls back to the flat look instantly.
- Palette extraction happens on a tiny downscaled copy of the committed background, so it costs one cheap computation per wallpaper change, not per frame.
- This release is validated on emulators; treat it as a beta and report problems with your device model and Android version.

## Privacy

Uno has no account service, analytics, or automatic crash upload. The internet permission exists only for fetching feed addresses you add. See the [privacy notes](../PRIVACY.md).
