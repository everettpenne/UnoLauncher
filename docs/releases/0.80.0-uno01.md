# Uno Launcher 0.80.0-uno01

Live Activities, as a first-class contract.

## What's new

- **A named contract.** The island's reading of Android 16's promoted ongoing notifications is now a pure, tested function (`LiveUpdateLogic.build`), with reference tests for the ride-share and delivery cases pinning title, short status, body, progress and color.
- **A closed, named field set.** PRIVACY.md now says exactly what the island reads for a Live Update, and a test fails if the code and the doc drift.
- **Compact Live Update text.** A new island setting chooses what a Live Update says on the pill: glyph only, short status (default), or title.
