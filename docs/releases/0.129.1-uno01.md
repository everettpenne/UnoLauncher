# Uno Launcher 0.129.1-uno01

The open island's liquid glass now shows with the accessibility service on.

## What's changed

- **The glass shows above the status bar too**: with the accessibility service on, Home's island is drawn in the service's own window, which could not see Home, so 0.129.0's glass band stayed black. It now bends the picture of the wallpaper Home keeps for the dock and widgets, and stays black over other apps.
- On Home, the closed pill has the same faint glass rim it has without the service.
- Includes everything in 0.129.0-uno01: the open island's glass band tinted by the playing track, the date opposite the time, and the widgets as one family.

## Install
