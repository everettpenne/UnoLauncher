# Uno Launcher 0.132.5-uno01

The assistant gesture opens search over the app you're in.

## What's changed

- **Search over the app.** With Uno Lab as your assistant app, the assist gesture now opens Uno's search on top of whatever app is in front instead of taking you to Home. Back, or a tap outside the panel, returns you to that app; opening an app from search takes you there. It is the same search as Home's: the bar grows out of the island, the results sit on their own card, the keyboard comes up, and Ask Qwen still gets the screen's text for a question about it.
- **The same liquid glass.** With Uno's accessibility service on (the one that draws the island above the status bar), search is drawn above the status bar too, and its glass bends the app behind it: the service takes one picture of the screen as search opens, kept in memory only and dropped when search closes. Without the service, search sits under the status bar and the system's live blur frosts the app behind it instead. Without that either ("Display over other apps"), the gesture opens Home's search as before.
- **Why it painted nothing before.** Search sized itself from its window's root view, which in a window of its own is still 0 x 0 the first time it is measured, so the panel was measured at nothing and never again. It now uses Compose's observed window size.
- Fixes found on the way: opening search a second time no longer crashes, and if the system stops the accessibility service while search is open, the next gesture still opens it.
- Needs Uno Lab 0.3.8, which aims the gesture at this search (older Uno Lab keeps opening Home's search).
