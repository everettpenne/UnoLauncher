# Uno Launcher 0.124.0-uno01

Find an app by what it does, not only by its name.

## What's changed

- **Search by description**: Spotlight and the App Library match an app's own one-line description as well as its name, so "notes" finds a notes app whatever it is called (three letters at least).
- **Descriptions on show**: the App Library shows each app's description under its name, and Spotlight beside the result.
- Includes everything in 0.123.0-uno01: continuous corners everywhere, Edge Highlight, a keyboard that matches the launcher, every emoji, Text Replacement and address-field keys.

## Install
