# Uno Launcher 0.77.0-uno01

Spotlight is the island's size, collapses instead of slides, and the glass rides the keyboard both ways.

## What's new

- **Same width as the island.** The search panel now shares the island's own width source (92% of the screen, clamped 336–372dp), so it is exactly as wide as the open island.
- **It collapses, not slides.** A swipe up on Spotlight shrinks the panel back into the pill under your finger (the emerge plays in reverse), and release past a short distance or with a flick finishes the collapse.
- **The glass rides the keyboard both ways.** The page dots and search button follow the keyboard's top edge smoothly while it opens and closes — no more holding still and snapping at the end.
