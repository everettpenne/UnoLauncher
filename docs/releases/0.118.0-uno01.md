# Uno Launcher 0.118.0-uno01

A squarer, more iOS corner for icons, folders and widgets.

## What's changed

- **Squircle**: icons, folders and widgets use a superellipse (exponent 5), the curve iOS's icon mask follows, so the corner eases in gradually instead of looking like a rounded rectangle.

## Install

Use **UnoLauncher-0.118.0-uno01-release.apk** from the release assets. Signed with the same key as 0.48.1 to 0.117.0-uno01, so it installs directly over them. Updating can switch off Notification access for Uno; turn it on again if the island loses track titles and artwork (Settings › Apps › Special app access › Notification access on GrapheneOS).
