# Uno Launcher 0.90.0-uno01

Three live activities spread around the island, and an Island debug page.

## What's new

- With three or more live activities, the first is on the main island, the second a circle on its left and the third a circle on its right. Every capsule is a circle showing the activity's symbol, and only as many are drawn on the right as fit before the screen's edge.
- A new Island debug page in Launcher settings: force dummy live activities on, and set the width and position of the main island and each capsule by hand, with the numbers copyable.

## Install

Use **UnoLauncher-0.90.0-uno01-release.apk** from the release assets. Signed with the same key as 0.48.1 to 0.89.0, so it installs directly over them.
