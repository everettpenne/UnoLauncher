# Uno Launcher 0.91.1-uno01

The island no longer takes touches while it starts, and a crash in its window is fixed.

## What's new

- The island's window now starts untouchable. It used to be added touchable and as big as the screen, so during a cold start it swallowed every touch meant for the app in front until the island had composed.
- Fixed a crash in the island's window: a frame measured before the screen's size was known could give a negative corner radius, which threw.

## Install

Use **UnoLauncher-0.91.1-uno01-release.apk** from the release assets. Signed with the same key as 0.48.1 to 0.91.0, so it installs directly over them.
