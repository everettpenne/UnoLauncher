# Uno Launcher 0.98.2-uno01

Uno Keyboard no longer blurs the app behind it unless you turn that on, after text in Signal's message box flickered with the blur on.

## What's changed

- The liquid-glass keyboard's blur of the app behind it is now a switch, **Blur the app behind the keyboard**, and it is **off by default**. The keys keep their glass look on a solid panel. If you turned "See-through glass" on in 0.98.0 or 0.98.1, it starts off again; turn the new switch on to get the blur back.
- The window no longer asks for blur for a moment when the keyboard first starts (it did, even with Classic style, before turning it off).

## Why

On a Pixel, with the glass style, typing a message in Signal that wrapped onto a second line made the text box flicker between what was typed and gibberish (the sent message was always right). Classic style did not do it. Blur behind the keyboard window is the only thing the styles do differently to any window but the keyboard's own, so it is now opt-in. This was not reproduced on the emulator, so the cause is not proven: **please confirm on the phone**, and if it still happens with the blur off, tell me.
