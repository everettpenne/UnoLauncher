# Uno Launcher 0.79.0-uno01

The island, simplified like Apple's.

## What's new

- **The tools are gone.** The long-press torch/timer/stopwatch grid is removed (one hidden gesture and one surface fewer). Timers and stopwatches still run in the island — start them from search ("timer 10", "stopwatch"), the Timers widget, or the control panel's torch. The compact island is now passive: tap to open, touch-and-hold to expand.
- **One drag.** Pull-to-peek, swipe-up-to-close, hold-open, and Spotlight's collapse all read their thresholds from a single `IslandDrag` home. Feel is unchanged; the plumbing is honest.
- **The island explains itself.** The open panel's first line says why it shows what it shows, and "What shows where" in settings maps every event to its one home.
- **Accessibility from the source.** State changes are announced to TalkBack once, where they happen; reply-send and play/pause are proper touch targets.
