# Uno Launcher 0.89.0-uno01

Live activities leave gracefully, and swap with a merge and split.

## What's new

- An ended activity's capsule slides back into the pill and melts in, with a small pulse; the pill's glyph and detail and the privacy dots shrink away instead of popping.
- Tapping a capsule merges it into the pill, then the old front detaches into the freed slot.
- Extra wide is 1% wider than the 75% size width, at the height you chose.

## Install

Use **UnoLauncher-0.89.0-uno01-release.apk** from the release assets. Signed with the same key as 0.48.1 to 0.88.0, so it installs directly over them.
