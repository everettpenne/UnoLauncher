# Uno Launcher 0.25.0-uno01

Pop-out bubbles beside the island, and an optional widget in the open island.

## What's new

- **Pop-out bubbles.** When more is going on than the pill can show (two things), the extras appear as small round bubbles beside it. Tap a bubble to bring that activity to the front.
- **Widget in the island (optional).** Customize, Control panel & extras, "Widget in the island": choose one Android widget for the open island to show. Android asks you to allow it. Nothing is shown until you choose one.

## Not in this release

A draggable pop-out island window (like HyperOS's) was investigated and not built: the island's windows are deliberately fixed-size and not touchable, and a movable one needs its own touchable window.

## Download and install

Use **UnoLauncher-0.25.0-uno01-release.apk** from the release assets. Signed with the same key as previous Uno releases, so it installs directly over 0.24.0. It still cannot install over a jakesgoodapps Duo Launcher build: uninstall that build first.

## Notes: what this has and hasn't been tested on

Bubbles were checked on an emulator with a centred camera and unit tested. **The island widget has not been run end to end** (choosing, showing, tapping), so please check it: pick a widget, open the island, tap the widget, remove it, and confirm Home's widgets are unaffected.
