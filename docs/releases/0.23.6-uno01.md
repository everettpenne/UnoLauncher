# Uno Launcher 0.23.6-uno01

Three fixes to the island: no more "vibrate" on every unlock, no more jump when it collapses, and a pause button that works without notification access.

## What was wrong

- **"Vibrate" on every unlock.** Android remembers the last ringer mode and hands it to anything that starts listening. The island starts listening each time it appears, so every unlock looked like the phone had just been put on vibrate.
- **A sideways jump on collapse.** Over other apps, the island's window was moved a little every frame while the island shrank, and the move arrived a frame behind the shrinking, so the island sat left of the camera and then slid back.
- **Pause did nothing.** The island can tell audio is playing without any permission, but pausing it needs notification access, and the fallback media key can be ignored from an app on newer Android.

## What's fixed

- The island ignores the remembered ringer and airplane-mode state when it appears. Real changes still show.
- With the camera on top, the island's window is anchored at its centre, the camera, so it shrinks around a fixed point and no longer jumps.
- Without notification access, pause now takes audio focus from the playing app and gives it straight back, which makes a well-behaved player pause and stay paused. If the audio is still playing, it tries the media key. With notification access on, the island uses the playing app's own controls, as in 0.23.4. Play after a pause and skip still use the media key.

## Notes: what this has and hasn't been tested on

On an emulator: the island window's centre stays fixed through a collapse, and after a screen off and on with the ringer on vibrate the island came up plain, with no vibrate pill. The emulator was slow, so treat both as rough checks.

Not tested, so please check on your phone:

- **Pause with NewPipe** (or any player) with notification access off. Android may refuse an audio focus request from a background app; if pause still does nothing, tell me whether the island shows the track title, and try turning the media details setting on.
- That **unlocking no longer shows "vibrate"** and a real change of the ringer switch still does.
- That **collapsing the island** no longer jumps.
