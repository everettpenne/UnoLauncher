# Uno Launcher 0.95.0-uno01

Settings you can search, an island you can line up with your status bar, and a tidier codebase.

## What's new

- Search in Launcher settings: find any setting by name or by other words for it, and go straight to its page.
- "Line up with the status bar" (The island): guides over the real status bar, moved until they sit between the icons, so the island never cuts one in half on your phone.
- "Keep the Home island still" (optional, with the accessibility service): the Home island stays at the camera while Android animates the launcher.
- The island's touch area comes from the same rectangles it draws, and the island page warns when the overlay mode will look grey.
- Code health: the island's code split by job, deprecated APIs replaced, dead code removed; the launcher compiles with no warnings.
