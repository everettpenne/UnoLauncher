# Uno Launcher 0.68.0-uno01

A polish release: app names you can read, clearer widget text, and a double tap to lock.

## What's new

- **App names you can read** over any wallpaper: 12 sp medium, with a soft dark halo behind the letters. Measured on the same Home screen, the faintest name went from 2.2:1 to 2.9:1 against its background and the average from 2.6:1 to 3.3:1.
- **Clearer widget text**: the small line under the clock and date widgets is larger and stronger.
- **Double-tap to lock** (Launcher settings, Gestures & feel; off by default): double-tap an empty spot on Home and the screen locks. It uses Uno's optional accessibility service, which Android requires for any app to lock the screen, and says what is needed when it is not running.
- **The Dynamic island's row in settings** has its own capsule icon.
- Everything from 0.67.0 (peek, hold open, recent notification, large navigation, smarter autocorrect) is unchanged.

## Notes: what this has and hasn't been tested on

Unit tests pass, and the emulator tests for the double tap (off by default; a single tap does nothing; a double tap asks to lock; without the service it reports so and does not crash), the island and the accessibility audit pass on an Android 16 emulator. **It has not been run on a real phone.** The double tap cannot lock on the emulator (its accessibility service is not enabled there), so the actual lock needs a check on the Pixel with the service on; the label legibility was measured on an emulator screenshot of the dune wallpaper. See `docs/device-checklist.md`.
