# Uno Launcher 0.64.0-uno01

Apple's type: a full HIG / SF Pro typography system in Inter, replacing Material's default type scale.

## What's new

- **A real type scale.** Uno now follows Apple's SF Pro rhythm — the eleven sizes from 34 down to 11, iOS line heights, and iOS tracking (large titles tracked looser, body and headline tighter) — set in the bundled Inter variable font. `UnoType` in `appearance/DuoTypography.kt` is the single source of truth; the glass UI kit reads from it too, instead of hard-coding sizes.
- **Regular body, semibold headers.** Body and footnote text are Regular and section headers are Semibold, matching SF Pro's weights rather than Material's "medium everywhere".
- **Consistent glass text.** The glass kit's buttons, rows, chips, fields and dialogs now pull from the scale, so every menu follows the same rhythm as the rest of Home.
- **What moved on screen:** section headers 16→17 semibold, help and note text 12→13 (Footnote), sheet titles 24→22 (Title 2), dialog titles 22→20 semibold (Title 3), body and guidance 14/16→16/17 (Callout/Body), page titles 28 medium→28 regular (Title 1), and kit buttons 14 medium→15 semibold.
- Tests: the full unit-test suite and lint run clean; the change is a `TextStyle` change only (no text or layout logic).

## Notes: what this has and hasn't been tested on

Unit tests and lint run clean, and the debug and unsigned release builds assemble. **This release has not been visually checked on a device or emulator**: sizes, weights, line heights and tracking changed app-wide. Worth eyeballing on a phone are a settings page (section headers at 17 semibold), a sheet title, a dialog title, and the glass buttons (15 semibold); watch for any `maxLines = 1` truncation in tight rows. The type change is a `TextStyle` change only — no text or layout logic changed.
