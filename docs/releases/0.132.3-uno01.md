# Uno Launcher 0.132.3-uno01

The assistant gesture now opens search **over the app you are in**, instead of taking you Home first.

## What's changed

- **A floating assistant window.** Home's search is part of the Home activity, so starting it from the assistant gesture brought the home task to the front and covered whatever you were doing. The assistant now gets its own translucent activity — `.search.AssistActivity` — in its own task, drawing the same search panel: same results, same suggestions, same **Ask Qwen**. Closing it puts the app back exactly where it was.
- **Home's search is untouched.** The island, the pull-down, the Search pill and the island's assistant card all still open search inside Home, as before. The floating window is only the system assistant's way in.
- **One app scan, not two.** `LauncherModel` is now created once per process instead of once per activity, so the floating window does not re-scan every app and its icons while somebody waits for search to appear.
- The floating window carries the screen's text with the question, exactly as the Home path does, and is excluded from recents.

## Notes: what this has and hasn't been tested on

The unit suites pass and the app builds. **Not tested on a phone for this release**: the floating window over a real app — whether the app behind stays visible, whether the keyboard comes up as it does in Home's search, and whether closing returns to the app without a Home flash. The phone was off the network when this was built.

Needs Uno Lab 0.3.6 to aim the gesture at the floating window; 0.3.5 still opens the Home path, which works but takes you Home as before.
