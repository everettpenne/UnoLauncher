# Uno Launcher 0.93.0-uno01

Taps near the top of the screen work again, and the island costs the apps under it far less.

## What's new

- Fixed: after the island had opened once, its touch window kept the open panel's size and took taps meant for the top of the app underneath (in-app back buttons, for one). It now shrinks back as soon as the island settles.
- The island's overlay window is only the top strip of the screen while the island is collapsed, instead of larger than the whole screen, so the app in front is blended and redrawn with far less work.
- A small saving in the island's clock work.

## Install
