# Uno Launcher 0.114.0-uno01

iOS-sized island corners, icons up to 125%, and apps that change their icon keep their place.

## What's changed

- **Island**: open corners 34 to 44 dp, as iOS's expanded island.
- **Icon Size** goes up to 125% (and down to 60%), in both layouts, without moving the grid.
- **An app that switches its own icon** (Seekur's App Icon setting) keeps its place on Home, in the dock and in its folder.

## Install

Use **UnoLauncher-0.114.0-uno01-release.apk** from the release assets. Signed with the same key as 0.48.1 to 0.113.0, so it installs directly over them. Updating can switch off Notification access for Uno; turn it on again if the island loses track titles and artwork (Settings › Apps › Special app access › Notification access on GrapheneOS).

## Notes: what this has and hasn't been tested on

Unit tests cover the icon range, the geometry at 125% and the alias hand-over; an emulator showed Home and the settings slider. **Not seen on the Pixel 10a:** the corners, the 125% icons or the icon-switch hand-over with a real switch.
