# Uno Launcher 0.86.0-uno01

The dock leaves cleanly into All apps.

## What's new

- Swiping into All apps now slides the dock and status rail fully off the left edge with the home page, instead of parking them on the left edge over the app list. Both edges now exit cleanly.

## Install

Use **UnoLauncher-0.86.0-uno01-release.apk** from the release assets. Signed with the same key as 0.48.1 to 0.85.0, so it installs directly over them.
