# Uno Launcher 0.98.1-uno01

A fix for Uno Keyboard's edits in apps that rewrite their own text box, and better autocorrect for dropped vowels.

## What's fixed

- Typing a long message in Signal could turn the text to gibberish once it wrapped onto a second line, with the box flickering between that and what was typed. Every keyboard edit is now one atomic batch edit; the app's real text is checked before anything is deleted (and left alone if it differs); and the keyboard no longer mistakes an app's own cursor change for one of its keystrokes.
- Autocorrect: a dropped vowel ("brwn", "ovr", "peple") is read back in rather than replaced by a commoner word several keys away.

## Notes: what this has and hasn't been tested on

Unit tests and lint pass. Typing and autocorrect were checked on an Android 17 emulator in Google Messages and in a test text box that rewrites itself on every change. **The Signal bug itself was not reproduced here** (Signal needs a registered phone number); the fix makes the keyboard safe against the way such apps change their text, and needs confirming in Signal on a real phone.
