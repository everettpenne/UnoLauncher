# Uno Launcher 0.23.1-uno01

Hotfix for the everywhere-overlay: touch, centering, and the runaway window.

## What was broken in 0.23.0

The island composable's full-size wrapper inside the wrap-content overlay window made the window expand toward covering the screen — which swallowed touches outside the island (the "barely responds" symptom), threw the island off-center, and the growing window bounds fed a relayout loop (the "going crazy" motion).

## What's fixed

- The overlay now renders **only the island itself**; the window is measured to exactly the island's bounds at all times, so only the island can receive touches and everything outside passes through.
- Window position/size updates are **deduplicated** — nothing is written to the window manager unless something actually changed, so no update can feed a layout loop.
- The island is anchored from the **system status-bar height** (overlay windows receive no status-bar insets), so it sits below the bar instead of overlapping it.
- Verified on-device: the window measures **326×95 px collapsed** and **840×389 px expanded**, centered, below the status bar; taps expand and collapse it in place, and there are no crashes.

## Notes

- The exact status-bar gap on real devices may need a dp or two of tuning — report how it sits on your phone.
- This release is validated on emulators; treat it as a beta.

## Privacy

Unchanged from 0.23.0: the overlay shows only what the island already shows on Home, stores nothing, and never draws on the lock screen. See the [privacy notes](../PRIVACY.md).
