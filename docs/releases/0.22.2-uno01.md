# Uno Launcher 0.22.2-uno01

Phase 1 of the SmartIsland-inspired live activities: calls and richer media in the island, built clean-room on the existing notification listener.

## What's new

- **Call card.** While a call is active, the island shows the caller's name (from the phone app's own call notification) and a ticking elapsed time — in the collapsed pill as a green phone icon and name, and in the expanded panel as a card. Tapping it opens the call screen.
- **Media card gets artwork and artist.** The expanded island now shows the album art thumbnail and the artist line under the track title, next to the existing previous/play/next controls and tap-to-open-player.
- **Privacy, GrapheneOS-style.** The caller name is held in memory only, shown on Home, and cleared when the call ends — never stored, and message text is never read. Everything rides the notification access you already granted; a **Show calls in the island** switch (on by default) lives under Notifications, and nothing works without notification access.

## What this is not (yet)

This is Phase 1: the island still lives on Home only. Overlaying other apps (SmartIsland's headline feature) needs `SYSTEM_ALERT_WINDOW` plus an opt-in foreground service — the Phase 2 work, which would come with its own explicit consent flow. See the notes below.

## Notes

- Caller detection requires the phone app to post an ongoing call-category notification — the behavior of the AOSP/Pixel dialer; other dialers usually do the same, and if not, the card simply doesn't appear (no crash, no wrong data).
- This release is validated on emulators; treat it as a beta and report problems with your device model and Android version.

## Privacy

Uno has no account service, analytics, or automatic crash upload. The call card and media card read only what the notification listener already provides, display it on Home, and store nothing. See the [privacy notes](../PRIVACY.md).
